# Replying to a customer about a late order

1. Look up the order first. Use the customer's first name and the item.
2. Say sorry once, in one sentence.
3. Never promise a delivery date. Say we will email them as soon as the courier updates the tracking.
4. If the order is 3 or more days late, give the code LATE10 (10% off their next order). Under 3 days: no code.
5. Keep it under 80 words. Sign it: Sam, Kettle & Bean support.
