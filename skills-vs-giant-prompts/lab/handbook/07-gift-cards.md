# Gift cards

## Facts
- Gift cards come in $25, $50 and $100 and are sent by email with a 16-character code.
- They never expire.
- They can be used for anything in the shop, including subscriptions, in one or several orders.
- They cannot be exchanged for cash or refunded, except where the law requires it.
- A gift card bought by mistake (for example twice) can be cancelled and refunded within 14 days if it has not been used.

## Steps
1. Balance question: ask for the last 4 characters of the code and the buyer's email, then tell them the balance.
2. Lost code: we can resend it to the email it was sent to. If the recipient's email has changed, we need the buyer to confirm by replying from the buyer's own address.
3. Code not working: ask for a screenshot of the error; most often the code was typed with a letter O instead of a zero. Our codes never use the letter O.
4. Refund request: only the "bought by mistake, unused, within 14 days" case. Otherwise explain kindly that gift cards can't be refunded, and remind them that they never expire.

## Never
- Never read out or email a full gift card code to anyone except its recipient's address.
- Never add value to a card by hand: ask Priya.
